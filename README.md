# Aviation & Travel Demand Analytics

## Objective
Analyze airline flight data to identify key drivers affecting ticket pricing.

## Tools
Python, Pandas, NumPy, Data Visualization

## Analysis
• Data Cleaning  
• Exploratory Data Analysis  
• Regression Modeling  

## Key Insights
• Travel demand impacts ticket prices  
• Airline and route influence pricing  
• Model achieved ~0.90 R² prediction accuracy

## Outcome
Built a predictive model to estimate airline ticket prices.
